# HƯỚNG DẪN QUẢN LÝ TÀI NGUYÊN (ASSET MANAGEMENT)

Thư mục này là trạm tập kết tài nguyên tĩnh (nguyên liệu) trước khi mở CapCut.

## Cấu trúc thư mục con:
1. `gameplay/`: Chứa các video footage nền đã quay sẵn, khuyến nghị crop hoặc quay ở tỷ lệ dọc **9:16 (1080x1920)** hoặc 16:9 full-HD.
   - Ví dụ: `DF_k416_ban_tam_trung.mp4`, `VLTK_tong_kim_combat.mp4`
2. `memes/`: Các đoạn video meme ngắn có nền xanh (green screen) hoặc meme phổ biến.
   - Ví dụ: `MEME_bat_ngo.mp4`, `MEME_dap_ban.mp4`, `MEME_chay_ngay_di.mp4`
3. `overlays/`: Ảnh thông số vũ khí, ảnh trang bị ngũ hành PNG trong suốt.
   - Có sẵn file mẫu: `safe_zone_tiktok_9x16.svg` (Kéo vào track trên cùng của CapCut để căn chỉnh không bị che phụ đề).
   - Ví dụ: `GUN_k416_phu_kien.png`, `ITEM_dai_lung_thuy.png`
4. `sfx/`: Hiệu ứng âm thanh ngắn (whoosh, click, gun-shot, fail sound).

## Quy ước đặt tên (Nhanh hơn khi tìm kiếm trong CapCut bằng `Ctrl + F`):
- Tiền tố rõ ràng: `GUN_`, `ITEM_`, `MEME_`, `SFX_`.
- Viết không dấu, phân tách bằng dấu gạch dưới `_`.
